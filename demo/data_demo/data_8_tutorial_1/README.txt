The tutorial 1 data (bodyCoil.dat, surfaceCoil.dat, brainScan.dat; about 7.9 GB) is stored on
Google Drive. Download it into this folder with

    python demo/data_demo/data_8_tutorial_1/download_data.py

then run the tutorial (examples/tutorial_1/tutorial_1.ipynb or tutorial_1.py).
If you already have the data from the MATLAB repository (monalisa/demo/data_demo/data_8_tutorial_1),
you can point the tutorial to that folder instead of downloading it again.
