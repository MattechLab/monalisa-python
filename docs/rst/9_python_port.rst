===============
The Python Port
===============

monalisa-python is a function-by-function port of the MATLAB toolbox, validated against
recordings of the MATLAB functions. These pages explain the names, the method and the validation.
The live status of each function is in
`PORTING_STATUS.md <https://github.com/MattechLab/monalisa-python/blob/main/PORTING_STATUS.md>`_.
